# Задание кодеру: перевод бота «Единорог» на новый стек

**Проект:** `D:\PYTHON\The Unicorn Model` — живой бот на VPS (`/opt/unicorn/`, systemd-сервис `unicorn`).
**Важно:** это НЕ cisdbot. Папку `D:\PYTHON\CISDBOT` не трогать вообще — это отдельный production-бот.
**Основание:** бэктесты и отчёты `results/STOP_VARIANTS.md` (варианты стопа, фильтр, сетка таймаутов), `results/STACK_MONEY.md` (расчёт на $100), прогоны — `results/trig_stack/`.

## Что меняется

| Параметр | Было | Стало |
| --- | --- | --- |
| Стоп | за другой край единорога (`setup["stop"]`) | **за лоу/хай бара-триггера** (поле `sweep_i`) |
| Тейк | 2R от стопа | 2R от стопа — пересчитается сам (формула `tp2_price` не меняется) |
| Фильтр 2R (отмена лимитки) | включён | **выключен полностью** |
| Выход | только стоп/тейк | стоп/тейк **или рынок через 6 часов** |
| Вход (лимитка 2ч), риск 1%, плечо, 9 пар, одна заявка на пару | — | без изменений |

Обоснование в цифрах: новый стек +2 015 R (PF 2.56, просадка −8.6 R) против +1 041.5 R у текущего (на 9 парах, 2020–2026). Детали — в отчётах.

## Правки по файлам

### 1. `bot/config.py`
Добавить параметр:
```python
# Выход по времени: если за это время не сработали стоп/тейк — закрыть по рынку.
# 6ч — оптимум бэктеста (поле 6–8ч; 6ч даёт лучшую просадку). См. results/STOP_VARIANTS.md.
TIME_EXIT_H = float(os.environ.get("TIME_EXIT_H", "6"))
```

### 2. `bot/rules.py`
а) `first_entry_event()` — убрать проверку 2R (фильтр отключён по бэктесту):
- удалить вычисление `tp2` и ветку `if saw and not filled: return "ran", i`;
- функция возвращает `("fill", i)` на первом касании входа в окне, иначе `("miss", -1)`;
- обновить докстринг: «работает как bt.execute._fill; фильтр 2R отключён по бэктесту — при широком стопе эффекта не даёт (см. results/STOP_VARIANTS.md)».

б) Добавить helper времени (одна точка для всех проверок):
```python
def time_exit_due(opened, now=None) -> bool:
    """True, если с открытия позиции прошло >= TIME_EXIT_H часов."""
```

в) Для записи времени-выхода: экономика как у стопа — выход по рынку, комиссия TAKER и слиппедж 1 б.п. против позиции (`SLIP`).

### 3. `bot/engine.py`
а) **Стоп за триггер.** В `_scan_pair` после `find_setups` для каждого сетапа посчитать стоп и передать его в `_consider`:
```python
trig_i = int(setup["sweep_i"])
trig_stop = float(df.iloc[trig_i]["low"]) if int(setup["side"]) == 1 else float(df.iloc[trig_i]["high"])
await self._consider(pair, setup, mss_open, sid, trig_stop)
```
В `_consider(...)` — использовать `trig_stop` в `round_levels(side, float(setup["entry"]), trig_stop, profile["price_tick"])` вместо `float(setup["stop"])`. Если `round_levels` вернул None — прежнее поведение (mark_seen и пропуск). Тейк и размер позиции пересчитаются сами в существующих функциях от нового стопа.

б) **Отключить фильтр 2R.** Удалить обработку `kind == "ran"` и вызовы `_cancel_ran` во всех местах:
- `_consider` (лог «2R уже был до входа, пропуск»),
- `_watch_limit`, `_paper_limit_live`, `_walk_limit_bars` (везде, где сейчас `if kind == "ran": await self._cancel_ran(rec)`);
- метод `_cancel_ran` удалить целиком.
- `cancel_card()` в messages оставить — он ещё используется при истечении лимитки по времени («2 часа вышли»).

в) **Выход по времени — бумажный режим** (`_watch_paper_pos`):
- если наступил дедлайн (`time_exit_due(pos["opened"])`) и стоп/тейк не сработали — закрыть позицию по последней цене (last_price, фолбэк — close последней закрытой минутки), слиппедж 1 б.п. против позиции, комиссия TAKER;
- журнал: reason `"time"`; в баланс зачислить net как обычно.

г) **Выход по времени — живой режим** (`_watch_live_pos`):
- если позиция ещё есть на бирже (`qty > 0`) и дедлайн наступил:
  1. `pos["closing_reason"] = "time"`; save;
  2. `await self.ex.market_close(pair, side, qty)`;
  3. дальше штатный путь: на следующем тике `position_qty == 0` → `_close_live`.
- в `_close_live` / `_reason_from_exit`: если `pos.get("closing_reason") == "time"` — reason `"time"` (не переопределять по цене);
- гонки: TP/SL могут сработать в ту же минуту — `market_close` с `reduceOnly` безопасен; ошибку закрытия залогировать и не падать.

д) `_hello()`: «выход только по стопу или тейку» → «выход по стопу, тейку или времени (6 ч)».

### 4. `bot/messages.py`
а) `close_card`: добавить reason `"time"` в маппинги — ico `"⏱"`, title «ВЫХОД ПО ВРЕМЕНИ».
б) `limit_card`: строку «Ожидание входа: 2ч | позиция: до стопа или тейка» → «Ожидание входа: 2ч | позиция: до стопа, тейка или {TIME_EXIT_H:g}ч».

### 5. `tests/test_rules.py`
а) `test_parity` — сверять `first_entry_event` теперь с `bt.execute._fill` (без 2R-ветки), а не с `_fill_limit`.
б) `test_2r_before_fill_cancels` — заменить на противоположный: касание 2R до входа НЕ отменяет заявку; для кейса lows=[100.5, 100.0], highs=[102.0, 100.2] ожидание `("fill", 1)`.
в) `test_same_bar_fill_beats_2r` — оставить (ожидание `("fill", 0)`).
г) Добавить тесты:
- стоп за триггер: синтетический df + setup(side, sweep_i) → `trig_stop` = low/high бара триггера;
- `time_exit_due`: opened=T → False при T+5:59 и True при T+6:01;
- закрытие paper-позиции по времени пишет reason `"time"` (по возможности).

## Критерии приёмки
1. `python tests/test_rules.py` → `ok` (и pytest, если установлен).
2. В SHADOW-режиме на первом же сетапе: в карточке заявки стоп = лоу/хай свечи-триггера (по графику: триггер — фитиль, снявший 4ч-уровень).
3. Лимитка НЕ снимается при проходе цены через уровень 2R (событий «2R без входа» в логах больше нет).
4. Позиция без стопа/тейка закрывается по рынку через 6ч, приходит карточка «выход по времени». Быстрая проверка: временно `TIME_EXIT_H=0.05` в тестовом запуске, затем вернуть 6.
5. Перезапуск с существующим `runtime/state.json` не ломается (старые позиции тоже получают time-exit от своего `opened`).
